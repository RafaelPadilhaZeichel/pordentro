Política de Privacidade

Última atualização: 26 de outubro de 2026

Esta política explica quais dados o Por Dentro Publisher ("Serviço") acessa quando uma conta do TikTok é conectada, e como esses dados são usados, em conformidade com a Lei Geral de Proteção de Dados (LGPD, Lei nº 13.709/2018).

1. Dados que acessamos

  • Informações básicas do perfil (nome de exibição e foto), obtidas pelo escopo user.info.basic, apenas para confirmar qual conta está conectada.
  • Token de acesso emitido pelo TikTok, necessário para enviar vídeos à conta autorizada.

Não acessamos mensagens, seguidores, dados de pagamento nem informações de outros usuários do TikTok.

2. Como usamos os dados

Os dados são usados somente para enviar e publicar vídeos na conta que autorizou o Serviço. Não usamos os dados para publicidade, perfilamento ou qualquer outra finalidade.

3. Armazenamento

O token de acesso fica guardado apenas no computador ou servidor do titular da conta, de forma privada. Nenhum dado é vendido, compartilhado ou transferido a terceiros, exceto ao próprio TikTok, necessariamente, para realizar o envio dos vídeos.

4. Retenção e exclusão

Os dados são mantidos apenas enquanto a conta estiver conectada. Ao revogar o acesso no aplicativo TikTok ("Configurações e privacidade" › "Segurança" › "Aplicativos e serviços autorizados"), o token deixa de funcionar e é apagado do nosso armazenamento.
